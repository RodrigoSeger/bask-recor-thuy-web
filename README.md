# Treino de Basquete — web build

Compiled web build (PWA) of the basketball training app, published here only so
GitHub Pages can serve it at `https://rodrigoseger.github.io/bask-recor-thuy-web/`.

- The application source code lives in a private repository.
- The only "secret" inside these files is the Supabase *publishable* key, which
  is a public client key by design; access control is enforced by Postgres RLS.
- Install on iPhone: open the URL above in Safari ▸ Share ▸ "Add to Home Screen".

Do not edit files here; they are overwritten on each publish.
